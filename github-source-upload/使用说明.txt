新增小动作和说话气泡
六个互动动作：甩尾、抛跳接、抱电脑站起跳、摔坏电脑再修好、伸懒腰、打盹。
在右键菜单中手动选择，原有的鼠标甩尾和双击抛跳接保留。
互动时会显示对应的短句；这是本地文案，不是 AI 对话，也没有语音。
闲时每隔约 90–180 秒随机做一个小动作并说句话。
专注计时期间不自动说话；右键关闭“偶尔说句话和做小动作”可保持安静。
“减少动画”也会暂停随机动作。
更新：先退出旧桌宠，再解压并运行新版本。偏好会保留。

这是一只独立运行的桌面伙伴，无需 ChatGPT、Python、Node 或 API Key。

开始使用
Windows 10/11（64 位）：先完整解压 ZIP，再双击“大肥鱼桌宠.exe”。
不要直接在压缩包里运行，也不要只移动 EXE；它旁边的运行文件需要保留。
Mac：选择适合自己芯片的包。Apple 芯片用 Apple芯片版，Intel 芯片用 Intel 版。
解压后把“大肥鱼桌宠.app”拖到“应用程序”，再打开。

基本操作
· 鼠标碰到大肥鱼：抱着电脑甩鱼尾巴。每隔约 6 秒可再次触发。
· 按住大肥鱼拖动：移动到桌面任意位置，位置会自动保存。
· 双击大肥鱼：播放“抛电脑 → 跳起 → 接住 → 坐回去工作”。
· 移到宠物附近会显示小工具条：甩尾、庆祝、设置。
· 右键点击大肥鱼或点击三个点：调大小、速度、减少动画、置顶、隐藏、退出。
· 菜单栏 / 系统托盘里也有大肥鱼图标，隐藏后可从这里重新显示。
· 键盘聚焦大肥鱼后：空格甩尾，回车庆祝。

慢一点看
右键 → 动画速度 → 慢慢来 0.5×。
默认速度 0.75×。独立桌宠的庆祝动画大约 4.5 秒，可通过速度菜单继续放慢。

完成后自动庆祝
右键 → 专注计时 → 5 / 25 / 45 分钟。
到时间自动庆祝。此独立版不读取 ChatGPT 或其他软件的任务状态。
不设置开机启动，不联网，不收集使用数据。

分发与首次打开
这是一份测试版分发包，尚未使用开发者证书签名，也没有完成 Apple 公证。
Mac 可能阻止首次打开；应由使用者确认来源后按 macOS 的正常提示允许打开。
Windows 可能提示未知发布者；不需要关闭杀毒软件或系统安全保护。
Mac 版使用了本地临时签名以保证包结构可运行；它不等于开发者身份签名或公证。

如果宠物消失
点击菜单栏 / 托盘图标 → 显示大肥鱼，或选择“移回屏幕右下角”。
退出：右键 → 退出大肥鱼。Mac 也可使用 Command+Q。
